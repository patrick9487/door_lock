# ATmega328P／Uno 接線

以下是 **Arduino Uno 的 D/A 標示**，不是 FPGA 的 Pxxx，也不是晶片封裝腳號。
預設為獨立的 5V Uno 系統。MCU、LCD、蜂鳴器模組與按鍵電路使用共同 GND。

## 4×4 按鍵

| 訊號 | Uno 腳位 | 按鍵位置 |
|---|---|---|
| ROW0 | D2 | 1、2、3、* |
| ROW1 | D3 | 4、5、6、D |
| ROW2 | D4 | 7、8、9、B |
| ROW3 | D5 | C、0、#、A |
| COL0 | D6 | 第一列 |
| COL1 | D7 | 第二列 |
| COL2 | D8 | 第三列 |
| COL3 | D9 | 第四列 |

每顆按鈕接於所屬 ROW 和 COL 之間。ROW 不直接接電源／地。
COL 已啟用內建上拉；需要外接上拉時，可各用 4.7k～10k 接此系統的 5V。
這僅適用於本 Uno 5V 版本；不要把這條 5V 接回原本的 FPGA I/O。

## LCD1602A：四位元模式

| LCD 腳位／訊號 | 連接 |
|---|---|
| 1 VSS | GND |
| 2 VDD | 5V |
| 3 VO | 10k 電位器中間端；電位器兩端接 5V、GND |
| 4 RS | D10 |
| 5 RW | GND（固定寫入） |
| 6 E | D11 |
| 7～10 D0～D3 | 不接 |
| 11 D4 | D12 |
| 12 D5 | D13 |
| 13 D6 | A0 |
| 14 D7 | A1 |
| 15 BLA、16 BLK | 依模組背光限流與極性接線 |

LCD 的資料腳名稱 D4 不等於 Uno D4，請依表格接線。
使用原本平行介面的 1602，不是 I2C 背板版本。

## 蜂鳴器與狀態

| 訊號 | Uno 腳位 | 行為 |
|---|---|---|
| 有源蜂鳴器模組 IN | A2 | 預設低有效，C 鍵觸發兩聲 |
| UNLOCK_EVENT | A3 | 正確密碼後輸出 100 ms 高脈衝 |
| ERROR_EVENT | A4 | 錯誤／位數不足時輸出 100 ms 高脈衝 |
| LOCKED_STATUS | A5 | 30 秒鎖定期間輸出高電位 |

蜂鳴器需使用帶驅動電路的有源模組，VCC/GND 依模組規格接線；
若模組是高有效，把 Config.h 的 BUZZER_ACTIVE_LOW 改成 false。
A3～A5 是邏輯訊號，未使用可不接；鎖具、繼電器及裸蜂鳴器需要適當驅動電路。
D0／D1 保留給序列埠。D13 已作 LCD 資料腳，不能另外用作狀態燈。

若改用裸 ATmega328P，還需依晶片規格配置電源、AVCC、去耦、reset 與 16 MHz 時鐘；
請先確認封裝及實際板子，勿直接把 Uno 的 D/A 編號當成晶片腳號。
